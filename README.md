# 'Cinéma découverte'
A modern, responsive website designed to bring local young people closer to the world of cinema. 
Discover movies, explore film information, and encourage young audiences to enjoy the big-screen experience in their local French community.

# Tools
- HTML5 — Provides the structure and content of the website.
- CSS3 — Handles styling, responsive layouts, visual effects, and animations.
- JavaScript (JS) — Powers interactive features and communication with the movie API.
- OMDb API — Supplies movie-related information.
  (API website: https://www.omdbapi.com/)

Note: An OMDb API key may be required to retrieve data. Configure your own key according to the API documentation and your project's setup.
